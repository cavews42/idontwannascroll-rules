숏폼 디톡스 개인정보처리방침

  • 앱 이름: 숏폼 디톡스 (스토어 제목: IdontWannaScroll - 릴스·쇼츠 차단)
  • 패키지명: com.cavew.noreels
  • 시행일: 2026년 10월 28일

1. 요약

숏폼 디톡스는 개인정보를 수집하거나 전송하지 않습니다. 모든 기능은 사용자의 휴대전화 안에서만 동작합니다. 인터넷은 릴스·쇼츠 탭을 찾는 규칙 파일을 내려받는 데만 쓰며(4절), 사용자 정보는 보내지 않습니다. 운영자는 사용자의 화면 정보, 설정값, 사용 기록, 기기 정보 중 어떤 것도 받지 않습니다.

2. 수집·전송하는 개인정보

없습니다. 이 앱은 분석·광고·오류 보고 도구를 쓰지 않으며, 화면 정보·설정값·사용 기록·기기 정보 등 어떤 정보도 기기 밖으로 보내지 않습니다.

3. 접근성 API 사용

이 앱은 릴스·쇼츠로 들어가는 길을 막기 위해 안드로이드 접근성 API를 사용합니다. 사용자는 앱 안의 "접근성 권한 사용 안내"에 직접 동의한 뒤에만 접근성 권한을 켜도록 안내받으며, 동의하기 전에는 접근성 서비스가 켜져 있어도 화면을 읽지 않습니다.

무엇을 읽나요

  • 인스타그램과 유튜브 화면의 구조 정보를 읽습니다. 화면 구성요소의 ID, 화면 위치, "릴스"·"Shorts" 같은 탭 이름이 여기에 해당합니다.
  • 다른 앱은 지금 화면에 인스타그램·유튜브가 떠 있는지 확인하는 데 필요한 정보(어떤 앱의 창인지, 창의 위치)만 확인합니다. 그 앱들의 화면 내용은 읽거나 저장하지 않습니다.

왜 읽나요

  • 릴스·쇼츠 탭과 릴스·쇼츠 영상 화면을 찾아, 탭을 가리고 다음 영상으로 넘어가면 처음 연 영상으로 되돌리거나 화면에서 빼내기 위해서입니다.
  • 이를 위해 화면 위에 탭을 덮는 표시를 띄우고, 필요할 때 뒤로 가기 동작을 대신 실행합니다.
  • 타이머 모드를 쓰면 하루 한도를 지키기 위해 릴스·쇼츠 화면을 본 시간을 잽니다.

어떻게 처리하나요

  • 모든 처리는 이 기기 안에서만 합니다. 읽은 화면 정보는 저장하지 않고, 어디로도 보내지 않습니다.
  • 인터넷은 인스타그램·유튜브가 업데이트되어도 계속 가릴 수 있도록, 탭과 영상 화면을 찾는 규칙 파일을 내려받는 데만 씁니다. 사용자 정보(화면 정보, 설정, 사용 기록, 기기 정보)는 보내지 않습니다.
  • 게시물, 메시지(DM), 댓글 등의 내용을 저장하거나 보내지 않습니다.
  • 접근성 권한은 언제든 휴대전화의 설정 → 접근성에서 끌 수 있습니다.

4. 규칙 파일 내려받기

인스타그램·유튜브가 앱을 업데이트하면 릴스·쇼츠 탭의 ID나 이름이 바뀌어 가리기가 풀릴 수 있습니다. 이를 빨리 고치기 위해 앱은 탭과 영상 화면을 찾는 규칙 파일을 내려받습니다.

  • 내려받기만 하고, 사용자 정보는 보내지 않습니다. 요청에 계정, 기기 ID, 화면 정보, 설정값, 사용 기록을 담지 않습니다. 기기 모델이 드러나지 않도록 요청 헤더에는 고정된 앱 이름과 버전만 씁니다.
  • 내려받는 때: 하루 한 번, 그리고 앱을 열 때.
  • 규칙 파일에는 화면 구성요소의 ID·탭 이름·색상 같은 데이터만 있고 실행 코드는 없습니다. 운영자의 서명을 확인한 파일만 쓰며, 이 파일로 인스타그램·유튜브 외의 앱을 대상으로 추가할 수 없습니다.
  • 규칙 파일은 GitHub Pages(GitHub, Inc.)에서 내려받습니다. 운영자는 접속 기록을 받거나 수집하지 않습니다. 다만 인터넷 요청의 특성상 GitHub가 서비스 운영과 보안을 위해 접속한 IP 주소 등을 기록할 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다.
  • 인터넷에 연결되지 않아도 앱은 내장된 규칙과 마지막으로 정상 동작한 규칙으로 동작합니다.

6. 제3자 제공 및 처리 위탁

없습니다. 규칙 파일은 GitHub Pages에 공개된 파일을 내려받는 것이며, 운영자가 GitHub에 사용자 정보를 제공하지 않습니다.
